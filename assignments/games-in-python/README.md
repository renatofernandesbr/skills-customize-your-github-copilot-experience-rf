
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Praticar o uso de strings, loops, condicionais e entrada de dados do usuário para construir um jogo clássico de adivinhação de palavras em Python.

## 📝 Tarefas

### 🛠️ Jogo da Forca

#### Descrição
Crie um jogo em que o jogador tenta adivinhar letras para descobrir uma palavra oculta antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória de uma lista predefinida
- Aceitar palpites de letras do usuário
- Mostrar o progresso atual da palavra com espaços em branco ou underscores (por exemplo: _ _ _)
- Registrar o número de tentativas restantes
- Encerrar a partida quando a palavra for adivinhada ou quando as tentativas acabarem
- Exibir mensagens claras de vitória ou derrota

### 🛠️ Melhorias na Experiência do Jogador

#### Descrição
Melhore a interação do jogo para deixar a experiência mais clara, amigável e dinâmica para o usuário.

#### Requisitos
O programa concluído deve:

- Validar entradas inválidas, como letras repetidas ou caracteres não permitidos
- Exibir as letras já tentadas pelo jogador
- Permitir jogar novamente após o fim de uma rodada
- Manter a lógica do jogo organizada em funções para facilitar leitura e manutenção
